4. How the System Works

From raw shopping data to personalized recommendations.

1. Dataset

Real REES46 shopping events plus added synthetic users and products.

2. Data Processing

Cleaning, then events turned into scores (view, cart, purchase).

3. Recommendation Model

Hybrid model: collaborative filtering, SVD, KMeans user groups and 7-day popularity are combined. Only new products are recommended.

4. Web Application

Enter a User ID for recommendations. New users pick categories and price instead.

Note: synthetic users are generated data used for the multi-category demo. The main performance result is measured on real users.
